# Okey Friends – Website

Statische Website (HTML + CSS + wenig JavaScript für die Sprachwahl) für GitHub Pages.
Kein Framework, kein Tracking, keine Cookies, keine externen Schriften oder Skripte.

- Sprachen: Deutsch (Standard), Türkisch, Englisch – Umschalter oben rechts (`?lang=de|tr|en`, wird nirgends gespeichert).
- Seiten: `index.html`, `impressum.html`, `datenschutz.html`, `konto-loeschen.html`, `support.html`, `einladen/index.html`, `404.html`
- App-Verknüpfung: `.well-known/assetlinks.json`, `.well-known/apple-app-site-association`
- Was der Besitzer noch eintragen muss: siehe **PLATZHALTER.md**.

> Die Rechtstexte (Impressum, Datenschutzerklärung, Konto löschen) sind ein **Entwurf und kein Rechtsrat**.
> Vor dem Store-Start prüfen lassen oder mit einem Generator (z. B. eRecht24, IT-Recht Kanzlei) abgleichen.
